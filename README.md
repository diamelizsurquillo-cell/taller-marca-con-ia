# Taller Presencial: Marca Profesional con IA
### De LinkedIn a tu Portafolio Web

Landing page oficial de alta conversión para el taller presencial organizado por **Canal Ejecutivo** & **Inspírate Creator**, con certificación oficial respaldada por la **Fundación San Marcos de la Universidad Nacional Mayor de San Marcos (UNMSM)**.

---

## 🚀 Características y Tecnologías
- **Frontend Puro:** HTML5 Semántico + Vanilla CSS + JavaScript ES6+.
- **Diseño White Theme Premium:** Glassmorphism sutil, tipografía Google Fonts (`Outfit` y `Plus Jakarta Sans`), micro-animaciones CSS y diseño 100% responsivo.
- **Simulador Interactivo en Vivo:** Demostración interactiva en la que el usuario escribe su nombre y cargo y visualiza en tiempo real su portafolio web con cambio de temas de color.
- **Tarifario Estratégico en Soles (PEN):**
  - **Pase Individual:** S/ 99
  - **Pase Grupal (a partir de 2 personas):** S/ 79 c/u
- **Checkout directo a WhatsApp:** Generación de ficha y mensaje preconfigurado para transferencias (Yape, Plin, BCP, BBVA, Interbank).

---

## 🛠️ Cómo ejecutar localmente

1. Clona el repositorio:
   ```bash
   git clone <URL_DEL_REPOSITORIO>
   cd "canal ejecutivo - inspirate creator"
   ```

2. Inicia el servidor local:
   ```bash
   node server.js
   ```

3. Abre en tu navegador:
   ```
   http://localhost:3000
   ```
